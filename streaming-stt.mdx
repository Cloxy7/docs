# Streaming Speech-to-Text (STT)

Learn how to use Waves' real-time Streaming Speech-to-Text API with minimal setup.

## Overview

The Streaming STT API lets you send live audio and receive partial or final transcripts in real time.  
This is ideal for conversational apps, voice assistants, and dictation tools.

## Requirements

- WebSocket client  
- Microphone access  
- Waves API key  
- PCM or WebM audio stream  

## Quick Example

```javascript
const socket = new WebSocket("wss://api.waves.ai/v1/stt/stream", {
  headers: {
    Authorization: "Bearer YOUR_API_KEY"
  }
});

socket.onopen = () => {
  console.log("Connected to STT server");
};

socket.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log("Transcript:", data.transcript);
};

socket.onerror = (err) => {
  console.error("WebSocket error:", err);
};

socket.onclose = () => {
  console.log("Connection closed");
};
````

## Audio Format

The API accepts:

- PCM 16-bit, 16 kHz
- WebM Opus streams

Send audio in small chunks (20–100 ms) for best latency.

## Response Format

```
{
  "type": "partial",
  "transcript": "this is an example"
}
```

Final:

```
{
  "type": "final",
  "transcript": "this is an example sentence"
}
```

## Closing the Stream

```
socket.send(JSON.stringify({ event: "close" }));
socket.close();
```

## Best Practices

- Stream audio frequently
- Avoid sending large chunks
- Close the WebSocket cleanly
