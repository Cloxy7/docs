# Waves Streaming Speech to Text (STT)

Waves Streaming STT provides low-latency, real-time speech recognition over WebSockets.  
Send audio frames and receive partial + final transcripts instantly.

## Endpoint

```txt
wss://waves-api.smallest.ai/api/v1/asr
````

## Required Headers

- Authorization: Bearer YOUR_API_KEY
- Content-Type: application/json

# Configuration

```
{
  "config": {
    "language": "en",
    "encoding": "linear16",
    "sample_rate": 16000,
    "enable_partial_results": true,
    "redaction": {
      "enable_numeric_redaction": false,
      "enable_pci_redaction": false
    }
  }
}
```

# Python Streaming Example

```
import websocket
import json
import time

API_KEY = "<YOUR_API_KEY>"
WS_URL = "wss://waves-api.smallest.ai/api/v1/asr"

def on_message(ws, message):
    print("RECV:", message)

def on_open(ws):
    config = {
        "config": {
            "language": "en",
            "encoding": "linear16",
            "sample_rate": 16000,
            "enable_partial_results": True
        }
    }
    ws.send(json.dumps(config))

    with open("audio.raw", "rb") as audio:
        while chunk := audio.read(3200):
            ws.send(chunk, opcode=websocket.ABNF.OPCODE_BINARY)
            time.sleep(0.04)

    ws.close()

headers = [f"Authorization: Bearer {API_KEY}"]

ws = websocket.WebSocketApp(
    WS_URL,
    header=headers,
    on_message=on_message
)

ws.run_forever()
```

# Best Practices

- Use 20–50 ms audio chunks
- Keep sample rate consistent
- Use partial results for UI updates
- Use final results for storage
- Enable redaction for sensitive audio
