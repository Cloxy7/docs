# **Streaming Speech - to - Text(STT)**

Waves Streaming STT provides low latency, real-time speech recognition over WebSockets. Send audio as small binary frames and receive partial transcripts instantly, followed by a final stabilized transcript at the end of each utterance.

## Endpoint

```
wss://waves-api.smallest.ai/api/v1/asr
```

## Required Headers

```
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
```

## Key Features

- Real-time partial and final transcripts
- Voice Activity Detection for accurate turn segmentation
- Sensitive data redaction (PCI, SSN, numeric redaction)
- Multiple encodings: `linear16`, `FLAC`, `mulaw`, `Opus`
- English + Indian language support (Hindi, Tamil, Telugu)
- Automatic punctuation and optional diarization
- Designed for ultra-low-latency streaming use cases

## Initial Configuration Message

Send this JSON immediately after opening the WebSocket.

```json
{
  "config": {
    "language": "en",
    "encoding": "linear16",
    "sample_rate": 16000,
    "enable_partial_results": true,
    "redaction": {
      "enable_numeric_redaction": false,
      "enable_pci_redaction": false
    }
  }
}
```

## Streaming Audio Frames

1. Open the WebSocket
2. Send the configuration message
3. Stream binary audio chunks (20–50 ms)
4. Close the socket after the final frame

## Streaming Example

```python
import websocket
import json
import time

API_KEY = "<YOUR_API_KEY>"
WS_URL = "wss://waves-api.smallest.ai/api/v1/asr"

def on_message(ws, message):
    print("RECV:", message)

def on_open(ws):
    config = {
        "config": {
            "language": "en",
            "encoding": "linear16",
            "sample_rate": 16000,
            "enable_partial_results": True
        }
    }
    ws.send(json.dumps(config))

    with open("audio.raw", "rb") as audio:
        while chunk := audio.read(3200):
            ws.send(chunk, opcode=websocket.ABNF.OPCODE_BINARY)
            time.sleep(0.04)

    ws.close()

headers = [f"Authorization: Bearer {API_KEY}"]

ws = websocket.WebSocketApp(
    WS_URL,
    header=headers,
    on_message=on_message
)

ws.run_forever()
```

## Sample Responses

**Partial Transcript**

```json

  "type": "partial",
  "text": "this is exa"
}
```

**Refined Partial**

```json
{
  "type": "partial",
  "text": "this is example te"
}
```

**Final Transcript**

```json
{
  "type": "final",
  "text": "this is example text",
  "confidence": 0.96
}
```

## Best Practices

- Use 20–50 ms audio chunks for stable latency
- Keep the sample rate and encoding consistent
- Use partial transcripts for UI updates and final transcripts for storage
- Enable redaction when handling sensitive speech
- Reconnect periodically during long-running sessions
